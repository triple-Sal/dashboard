# ⛰️ הדאשבורד שלי

דאשבורד בעברית בסגנון הרים, עם:
1. באנר רץ של חדשות ישראל (N12)
2. באנר רץ של חדשות חו"ל (FreshPlaza Europe)
3. שערי דולר ואירו מול השקל
4. המדדים ת"א 35 ו-S&P 500
5. מזג האוויר בתל אביב, היום ו-3 ימים קדימה

## איך זה עובד, בשתי שורות
- **הרובוט** (`.github/workflows/update.yml` + `scripts/fetch-data.mjs`) רץ ב-GitHub כל 15 דקות, אוסף חדשות, שערים ומדדים, ושומר אותם בתיקיית `data`.
- **הדף** (`index.html`) קורא את הקבצים האלה ומציג אותם. מזג האוויר נטען ישירות מ-Open-Meteo.

## מה נמצא איפה
| קובץ | מה הוא עושה |
|---|---|
| `config.js` | **כל ההגדרות במקום אחד**: כותרת, מקורות חדשות, מטבעות, מדדים, עיר, מהירות הבאנר |
| `index.html` | השלד של הדף: איפה כל רכיב יושב |
| `css/style.css` | העיצוב: צבעים, רקע ההרים, גדלים |
| `js/main.js` | מפעיל את כל הרכיבים |
| `js/widgets/` | קובץ נפרד לכל רכיב (באנר, מט"ח, מדדים, מזג אוויר, שעון) |
| `js/icons.js` | האייקונים |
| `scripts/fetch-data.mjs` | הרובוט שאוסף את הנתונים |

## שינויים נפוצים
- **להוסיף מטבע** (למשל ליש"ט): ב-`config.js`, תחת `currencies`, להוסיף שורה
  `{ code: 'GBP', name: 'לירה שטרלינג', symbol: '£', yahoo: 'GBPILS=X' }`
- **להוסיף מדד** (למשל נאסד"ק): תחת `indices`, להוסיף
  `{ name: 'נאסד"ק', country: 'ארה"ב', flag: '🇺🇸', yahoo: '^IXIC' }`
- **להחליף עיר**: לשנות את `city`, `latitude`, `longitude` תחת `weather`
- **להאט את הבאנר**: להקטין את המספר `speed`
- **לשנות צבעים**: בראש `css/style.css`, תחת `:root`

## הפעלה ידנית של הרובוט
ב-GitHub: לשונית **Actions** ← **Update dashboard** ← **Run workflow**.
